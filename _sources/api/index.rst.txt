API Reference
=============

Each subpackage is documented once, at its own path. The top-level ``pinnlab``
namespace re-exports most of these names for convenience; documenting both it
and the subpackages with ``:members:`` described every re-export twice, which
is what produced the duplicate-object warnings that blocked building with
``-W``.
